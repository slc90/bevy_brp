Queues App-owned Custom Pointer scroll in Bevy apps via bevy_brp_extras. Supports Line and Pixel units in horizontal and vertical directions.

Scroll units: Line (default text line scrolling), Pixel (precise pixel-based scrolling)

Examples:
```json
{"x": 0.0, "y": 5.0, "unit": "Line"}      // Scroll down 5 lines
{"x": 3.0, "y": 0.0, "unit": "Line"}      // Scroll right 3 lines
{"x": 0.0, "y": -100.0, "unit": "Pixel"}  // Scroll up 100 pixels
```

Queues Custom Pointer scroll at the last independent BRP logical position for the target window (origin initially). Line/Pixel units are preserved. Does not write raw MouseWheel or move the OS cursor. Window defaults to the last live BRP target, then PrimaryWindow; invalid explicit/destroyed targets fail. Acceptance does not prove a UI result.
Prerequisites: BrpExtrasPlugin, enabled PickingPlugin and InteractionPlugin, and a host-provided picking backend. Native Window move/resize is unsupported.
