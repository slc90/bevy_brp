Delete application and watch logs from the system temp directory.

Examples: {"source":"watch"} or {"source":"app","app_name":"test_app","older_than_seconds":3600}.
source defaults to "all" (application and watch logs). app_name cannot be combined with source="watch".
Use brp_list_logs to preview. Deleted filenames and count are returned; a deletion failure is an error.
Server trace is never deleted by this tool, including when no filters are supplied.
