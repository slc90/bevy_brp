Queues an ordinary widget drag through Custom Pointer Picking input: establish the start hit, press, interpolate to the endpoint, then release after the endpoint is consumed. frames is the number of interpolation steps (minimum 1); setup and release add Picking cycles. The response confirms acceptance, not UI success.

Button options: Left, Right, Middle

Examples:
```json
{
  "button": "Left",
  "start": [100.0, 100.0],
  "end": [300.0, 200.0],
  "frames": 30
}  // Drag over 30 frames for smooth animation
```

Coordinates are logical window pixels. Window defaults to the last BRP target, then primary. Waits for existing timed holds; later input waits until completion. Does not write raw mouse input or the OS cursor. Native Window move/resize regions are unsupported and must be avoided.

Prerequisites: BrpExtrasPlugin, enabled PickingPlugin and InteractionPlugin, and a host picking backend.
