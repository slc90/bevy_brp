Moves an App-owned Custom Pointer via bevy_brp_extras without changing the system cursor or raw mouse channels. Supports delta and absolute logical window coordinates with optional window targeting. Physical input does not update the BRP position history. Requests accept queued input; they do not prove a UI result.

Movement modes:
- Delta: Relative movement from current position
- Absolute: Move to specific coordinates

Examples:
```json
{"delta": [50.0, 30.0]}                    // Move right 50px, down 30px
{"position": [200.0, 150.0]}               // Move to absolute position
{"position": [100.0, 100.0], "window": 42} // Target specific window
```

Prerequisites: BrpExtrasPlugin, enabled PickingPlugin and InteractionPlugin, and a host-provided picking backend. New physical Mouse move/press/scroll cancels this pointer and hands control back. Native Window title-bar move and edge resize are unsupported.
